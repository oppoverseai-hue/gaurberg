What a ticker changes in the app:
- None of these companies is a seed, so none gets its own map (`isMapped` needs `is_seed`).
- A ticker with `markets = ['US']` switches on live quotes and news in previews (`listing.ts`: live data only when the first market is US).
- `markets` can only hold US, LSE or HKEX. A listing anywhere else keeps `markets` empty, and the ticker is shown but never looked up live.
- `ticker` is unique across all exchanges, so a bare code (for example `0700` or `005930`) can collide later.
